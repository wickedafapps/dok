Installation

Install Dok, optionally with a curated set of core services.

Prepare this server for Dok

This container has privileged access to the Docker host. Choose how much of the stack Dok should install, and it will write the configuration, build the image, launch Dok, and configure the selected core services. Installation data and snapshots stay in the separate maintenance store so an exact reinstall never needs the same answers twice.
